🚀 Excited to unveil **Horizon-Veridian**: Closed-Loop Sprint Governance powered by Gnani AI & LangGraph!

Ever sat through an engineering sprint sync where:
❌ An AI bot spammed 15 unreviewed Jira tickets mid-meeting?
❌ Tasks got assigned to teammates who are currently on paternity leave?
❌ Unapproved legacy endpoints and budget overruns slipped past code review?
❌ Ticket status updates required endless Slack pings and manual board grooming?

We built **Horizon-Veridian** to solve this once and for all:

1️⃣ **Multilingual Speech Ingestion:** Meetings conducted in conversational Hinglish are transcribed with speaker attribution via **Gnani Prisma v3.0**.
2️⃣ **4-Way Compliance Firewall:** Before a single ticket is created, LangGraph checks security policies, budget caps, blocked APIs (`SEC-POL-104`), and HR leave status.
3️⃣ **Smart Leave Redirection:** If a teammate is on leave, the system recommends re-routing their task to the domain peer with the lowest active workload.
4️⃣ **Zero Tickets Pre-Approval:** The Engineering Manager receives an interactive Block Kit Review Menu in Slack. **ZERO Jira tickets are created without explicit approval**.
5️⃣ **Individual 1-on-1 Slack DMs:** Upon approval, verified Jira issues are generated in the `SCRUM` project, and isolated 1-on-1 DMs are sent to engineers.
6️⃣ **Evidence-Based Auto-Close:** When an engineer replies with a PR link (`github.com/.../pull/...`) or commit hash, the ticket automatically transitions to **Done** in Jira with an immutable audit trail!

Built with:
⚡ Next.js 15, FastAPI & Flask
🧠 Gnani AI Evon 30B & Prisma v3.0 / Google Gemini
🛡️ Supabase pgvector with Row Level Security (RLS)
💬 Slack Block Kit & Jira Cloud REST API v3
